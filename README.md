# DIY 手账本 / DIY Journal

把 Harness 拼成自己的手账：纸面、胶带、照片白边、小飞机、信封和电话簿。

[English](README.en.md) · [安装与更新](INSTALL.md) · [皮肤说明](skins/diy-journal/README.zh.md) · [功能演示](docs/FEATURES.md) · [独立样式菜单插件](https://github.com/Alphazerolan/diy-journal-settings)

The skin contains generated assets; no personal input photos, local paths or
runtime credentials. Character clearance remains disclosed in the skin NOTICE.

## 这版改了什么

- 主界面：手写标题、纸面与区域配图。
- 左侧：书本式工作区、笔刷高亮、小飞机、纸质账户及用量卡。
- 对话：折叠信封与展开信纸；右侧工作区使用蓝色夹板和彩色入口。
- 设置与工具：独立配图、菜单、审批卡片、参数卡和不透明弹窗。
- 可选编辑器：自选照片、单双照片、位置角度、白边题字和胶带颜色纹样。

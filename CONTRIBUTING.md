# 贡献说明 / Contributing

本仓库维护皮肤和使用文档。提交问题时请附 Harness 版本、皮肤版本、复现步骤及脱敏截图。
照片编辑器的问题请到[插件仓库](https://github.com/Alphazerolan/diy-journal-settings)反馈。

修改后运行 `node scripts/check-release.mjs`（Node.js 20+）。界面改动需检查浅色、深色和窄窗口。
请勿提交个人配置、密钥或未经授权的素材；素材与许可变更需附可核验来源。

This repository maintains the skin and its user documentation. For bug reports,
include Harness and skin versions, reproduction steps and redacted screenshots.
Report editor issues in the [plugin repository](https://github.com/Alphazerolan/diy-journal-settings).

Run `node scripts/check-release.mjs` with Node.js 20+ after changes. Check both
themes and narrow windows for visual changes. Do not commit personal configuration,
secrets or unauthorized assets. Changes to provenance or licensing need verifiable sources.
